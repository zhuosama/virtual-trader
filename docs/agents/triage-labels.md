# Triage Labels

Use this default five-role vocabulary for future issues or local task status.

| Role | Label |
|------|-------|
| Needs maintainer evaluation | `needs-triage` |
| Waiting on reporter/user detail | `needs-info` |
| Ready for AFK agent execution | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be actioned | `wontfix` |

For Hxx task documents, map these labels to prose status when no issue tracker is involved.
